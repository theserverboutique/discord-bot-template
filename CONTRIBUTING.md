# Contributing

Thank you for your interest in contributing to **Discord Bot Template**!

Contributions of all sizes are welcome, whether it's fixing a bug, improving documentation, suggesting a new feature, or submitting code.

---

## Before You Start

Please:

- Check existing issues before opening a new one.
- Keep pull requests focused on a single change.
- Follow the existing coding style.
- Write clear commit messages.
- Test your changes before submitting.

---

## Reporting Bugs

When reporting a bug, please include:

- A clear description of the issue
- Steps to reproduce it
- Expected behaviour
- Actual behaviour
- Your Node.js version
- Your Discord.js version
- Any relevant error messages

---

## Suggesting Features

Feature requests are always welcome.

Please explain:

- The problem you're trying to solve
- Your proposed solution
- Any alternative ideas you've considered

---

## Pull Requests

Before submitting a pull request, please ensure:

- Your code follows the project's style.
- Documentation has been updated if necessary.
- Existing functionality has not been broken.
- New features are appropriately documented.

---

## Code Style

This project aims to remain:

- Clean
- Readable
- Modular
- Well documented
- Easy to maintain

Whenever possible, prefer reusable solutions over duplicated code.

---

## Questions

If you have any questions about contributing, feel free to open a discussion or issue.

We appreciate every contribution that helps improve the project.
