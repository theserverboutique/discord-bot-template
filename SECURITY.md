# Security Policy

Thank you for helping keep **Discord Bot Template** secure.

If you discover a security vulnerability, please report it responsibly so it can be investigated and resolved before public disclosure.

---

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x | ✅ |
| < 1.0 | ❌ |

---

## Reporting a Vulnerability

Please **do not** create a public GitHub issue for security vulnerabilities.

Instead, contact The Server Boutique privately with:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (if available)

We will:

- Acknowledge your report as soon as possible.
- Investigate the issue.
- Keep you informed of our progress.
- Release a fix if the report is confirmed.

---

## Responsible Disclosure

We kindly ask that you:

- Give us reasonable time to investigate.
- Avoid publicly disclosing vulnerabilities until a fix has been released.
- Provide enough information for us to reproduce the issue.

Responsible disclosure helps protect everyone using this project.

---

## Security Updates

Security fixes will be documented in the project's **CHANGELOG.md** and released as soon as practical.
